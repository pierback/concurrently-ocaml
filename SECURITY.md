# Security Policy

## Supported versions

Security fixes are made against the latest tagged release and the current
default branch. Older prerelease versions are not maintained.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a
vulnerability** form in this repository's Security tab. Do not include exploit
details, credentials, tokens, or other sensitive data in a public issue.

If private reporting is unavailable, open a public issue containing only a
request to establish a private channel. A maintainer will respond without
asking you to disclose the vulnerability publicly.

Include the affected version or commit, platform, impact, and the smallest safe
reproduction you can provide. You should receive an acknowledgement within
seven days and a triage update after the report has been reproduced.
